§ paragraf

Ask about the Polish Labour Code in Polish, English or Ukrainian. Answers come only from the articles of the consolidated text (Dz.U. 2026 poz. 1245) as they read on the date you choose, and every citation is checked by code against the law's own words.

Calculations read pay from comp-ledger over MCP. Demo employees: E-1001 (raise on 1 July 2026), E-1002 (since 15 June 2026), E-1003 (since 2019), E-2001 (paid in EUR).
